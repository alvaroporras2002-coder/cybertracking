# Imágenes del programa

Seis ilustraciones conceptuales generadas con la herramienta integrada de imágenes de ChatGPT para CYBERTRACK 1.3. No se usa una API de IA al navegar por la aplicación.

Las ilustraciones identifican las etapas; no son diagramas técnicos ni sustituyen los temas, tareas o referencias del aula. Los originales se adaptaron a WebP para la web, conservando su contenido.
