# Portadas semanales

52 imágenes creadas con la herramienta integrada de imágenes de ChatGPT, mediante una generación distinta para cada semana. El inicio y el aula reutilizan la portada de su semana para conservar el contexto; no se reutiliza una portada entre semanas diferentes.

Son ilustraciones conceptuales del temario, no capturas de herramientas ni diagramas técnicos. La aplicación sirve los WebP desde el repositorio y no hace llamadas a una API de IA.
